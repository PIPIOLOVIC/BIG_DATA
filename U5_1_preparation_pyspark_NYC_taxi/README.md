# U5.1 — Preparación de PySpark y exploración de NYC Taxi

Práctica introductoria de **PySpark** ejecutada localmente en VS Code usando un entorno virtual `.venv` (Python 3.12) y lectura remota por rangos HTTP de un archivo Parquet de NYC Yellow Taxi (enero 2025) mediante PyArrow, sin descargar el dataset completo a disco.

## Requisitos
- Python 3.12
- Java (JDK 17 o 21)
- Paquetes en `.venv`: `pyspark`, `ipykernel`, `pyarrow`
